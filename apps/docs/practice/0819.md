## Day 4 --- single / multiple 상태 설계

### 목표

UI보다 **상태 모델링과 toggle 로직**에 집중한다.

### 구현 전에 먼저 적기

```text
single
같은 값을 누르면? 열려있을 땐 닫힌다.
다른 값을 누르면? 열려있던 것이 닫히고 누른 값이 열린다.

multiple
배열에 이미 있으면? 배열에서 뺀다. 열려있었으면 닫힌다.
배열에 없으면? 배열에 넣는다. 열린다
```

### 상태 모델

```text
single
→ string | null
? 하나만 열 수 있기 떄문에 열린 Item의 식별값 하나만 저장한다. 아무것도 열려 있지 않는 상태는 null로 표현한다.

multiple
→ string[]
? 여러 Item이 동시에 열릴 수 있기 때문에 열린 Item의 식별값들을 배열로 저장한다. 아무것도 열려 있지 않은 상태는 빈 배열 []로 표현한다.
```

### 할 일

- [x] `type: "single" | "multiple"` 정의
- [x] single 상태 구조 결정
- [x] multiple 상태 구조 결정
- [x] single: 같은 Item 클릭 → 닫기
- [x] single: 다른 Item 클릭 → 교체
- [x] multiple: 닫힌 Item 클릭 → 추가
- [x] multiple: 열린 Item 클릭 → 제거
- [x] 두 모드 직접 테스트

multiple
