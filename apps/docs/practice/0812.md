## Day 3 --- Compound Component + Context로 변경

### 목표

Day 2에서 만든 코드를 아래 API로 바꾼다.

```tsx
<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger>Section 1</AccordionTrigger>
    <AccordionContent>Content 1</AccordionContent>
  </AccordionItem>
</Accordion>
```

1. 역할별 컴포넌트 분리

   → 뭐를 누구한테 내려줘야 하는지 직접 확인

- [x] props drilling이 어디서 생기는지 확인
      → Item은 안 쓰는데 Trigger/Content 때문에 props를 받는가?
      → 여러 단계로 값 전달이 생기는가?

4. 그다음 AccordionContext

Accordion 전체 범위에서 공유해야 하는 값

- openValue
- clickToggle

현재 Item 범위에서만 공유해야 하는 값

- sectionId(itmeValue)

- [x] AccordionContext 만들기

      → openValue
      → toggle

5. 그다음 AccordionItemContext

- [ ] AccordionItemContext 만들기
