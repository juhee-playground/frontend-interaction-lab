## 오늘 헷갈렸던 것

### onClick={fn}과 onClick={() => fn(value)} 차이

- `onClick={fn}`
  - 함수를 실행하는 것이 아니라 함수 자체를 전달한다.
  - 클릭했을 때 `fn`이 실행된다.

- `onClick={() => fn(value)}`
  - 매개변수를 넘겨야 할 때 새로운 함수를 전달한다.
  - 클릭했을 때 그 함수 안에서 `fn(value)`가 실행된다.

- `onClick={fn()}`
  - 함수 호출이므로 렌더링 중 바로 실행된다.

### `&&`, `??` 차이

- `조건 && 값`
  - 앞의 조건이 true이면 뒤의 값을 사용한다.
  - React에서 조건부 렌더링할 때 자주 사용한다.

- `값 ?? 기본값`
  - 앞의 값이 `null` 또는 `undefined`이면 뒤의 기본값을 사용한다.
  - 예: `data.items ?? []`
